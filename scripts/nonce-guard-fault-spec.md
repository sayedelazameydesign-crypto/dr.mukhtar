# محاكاة حارس nonce — تجربة معزولة

`nonce-guard-model.js` مجدول حتمي داخل عملية Node واحدة، يقبل قيم اختبار تبدأ بـ`fixture-`
فقط. لا يضيف مصادقة أو `doPost` أو اتصالًا أو حق الوصول إلى Requests وCalendar. لا يدّعي أن
الكتابة إلى Sheets ذرية أو أن استهلاك nonce يجيز الحجز.

## ما تفعله التجربة

كل محاولات الاختبار المتعاونة تنتظر القفل الوهمي. يقرأ المالك السجل الوهمي ثم يكتب أثناء
احتفاظه بالقفل؛ يرفض اللاحق nonce المرصود سابقًا. اختبار العشرة يجد استهلاكًا واحدًا وتسعة
رفضات في الترتيب المجدول، **وليس 10 طلبات متزامنة حقيقية أو اختبار `fetchAll`**. حتى نجاح
الاستهلاك أو رفض التكرار لا يحسم نتيجة حجز سابق. الفحص والكتابة خطوتان في الاختبار لا عملية
تخزين ذرية موحدة، ويسمح ذلك بحقن الأعطال بينهما.

تُختبر أخطاء القراءة، وتلف الصفوف أو تكرارها، وانتهاء انتظار القفل دون فك قفل غيره، والسقوط
قبل الكتابة أو بعد أن تُطبّق. حالتا عدم تطبيق الكتابة وتطبيقها تعيدان النتيجة العامة نفسها
`NONCE_STORAGE_UNKNOWN`، والردود لا تحتوي nonce. بعد نتيجة ملتبسة تمنع علامة غموض **وهمية
داخل العملية** المحاولات التالية وتطلب مراجعة. `staff-warning-model.js` يعرض تحذيرًا ثابتًا
عند غموض النتيجة أو ضياع الرد، دون عرض بيانات الطلب أو nonce أو الخطأ الداخلي. سقوط الخادم
قد يمنع إصدار أي رد؛ اختبار التحذير يفترض أن المستدعي لاحظ فشل القراءة أو مهلة الرد.

## حدود السلامة

- القفل والبيانات وعلامة الغموض هنا ليست دائمة؛ بعد إعادة إنشاء النموذج تضيع العلامة. الاختبار
  يوضح ذلك صراحة ولا يقدمه كآلية استرداد. لا يوجد عزل محفوظ، ولا تغلق التجربة اللوحة الحقيقية.
- تحرير القفل فور وقوع السقوط **افتراض في المجدول** لا برهانًا على توقيت تحرير Script Lock.
  كما لا تختبر المحاكاة كتابًا خارجيين يتجاوزون القفل أو انقطاع العملية قبل حفظ علامة الغموض.
- لا توجد معاملة بين nonce والطلب والتقويم، ولا ارتباط مثبت بين nonce وطلبه في جدول ذي عمودين.
  فشل أو غموض الاستهلاك لا يُحل بإعادة آلية، ولا بحذف أحداث أو تحرير مطالبة حسب عمرها.
- يلزم قبل التنفيذ الفعلي تصميم حظر دائم قابل للاسترداد، واختبارات Google معزولة للتنافس
  ونتائج الكتابة الملتبسة وتزامن بقية الكتاب والمصادقة. هذه المحاكاة لا تستنفد الأعطال.

شغّل مباشرة: `node scripts/test-nonce-guard-model.js`؛ تُشغّل أيضًا ضمن `npm test` و`npm run gates`.
