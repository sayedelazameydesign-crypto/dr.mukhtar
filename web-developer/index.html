Web Developer — feature dashboard

This is an isolated developer tool living in web-developer/. It does not change the clinic booking site, is not part of the Apps Script bundle, and is not published by the Pages workflow.

  • Standalone mode (this preview): every feature acts on the demo page in the frame above. Reload it to start over — active toggles are re-applied automatically.
  • Extension mode: load web-developer/ as an unpacked Chrome extension (chrome://extensions → Load unpacked). The popup then drives the active tab through a content script.
  • All 63 requested roadmap items plus the 13 base features they build on are in FEATURES.md with their upstream links.
  • No network calls are required: validators, spelling, accessibility, contrast and colour checks all run locally. A remote validator is used only if you configure one.
