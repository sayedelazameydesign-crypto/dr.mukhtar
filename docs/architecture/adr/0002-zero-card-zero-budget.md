# ADR-0002 — صفر بطاقة وصفر اشتراك (قيد صلب)

- **الحالة:** مقبول (Accepted)
- **التاريخ:** 2026-11-06

## السياق

العيادة مشروع حقيقي بفريق صغير بلا فريق تقني متفرغ وبلا ميزانية أدوات. أي اشتراك «بسيط» ينتهي بحساب موقوف، أو بطاقة منتهية تتوقف معها البوابة في منتصف شهر، أو بيانات صحية عالقة لدى مزود لم يعد مدفوعًا.

## القرار

1. **كل خدمة خارجية في المنظومة يجب أن تكون `card_required: false`** — موثقة في `docs/free-tiers.json` (اليوم: 23/23 خدمة) ومفروضة بفحص في CI.
2. **لا اشتراك شهريًا لأي جزء** — بما فيه مراقبة الأداء، تحليل المستخدمين، التصاريح، الروابط المختصرة.
3. **التكلفة المحظورة تشمل «المجاني مؤقتًا»** — التجارب المدفوعة  التي تتحول لاحقًا إلى فواتير ممنوعة بحكم القرار نفسه.
4. إن تعذر إنجاز حاجة بخدمة مجانية حقيقية: يُسجَّل ذلك **كفجوة** (انظر G23 — WhatsApp غير مثبت) لا كاشتراك.

## النتائج

- CTO-anything بقيمة غير صفرية ممنوعة: لا «Docker paid» ولا «Vercel Pro» ولا «SendGrid paid».
- النشر على GitHub Pages + Apps Script + Sheets/Calendar + التحليلات = مستحيل هنا — لا توجد analytics أصلًا (انظر ADR-0006).
- ثمن هذا القرار: بعض الكماليات (CDN عالمي، صور متقدمة، واجهات مراقبة جاهزة) مستحيلة في هذا الطور. مقبول.
- أي اقتراح أداة في issue/PR يبدأ من السؤال: **أين مصدر بطاقة الائتمان؟** الإجابة «لا توجد» شرط دخول.

## لماذا هذا قرار هندسي لا مالي

لأنه يحدد شكل المعمارية: GAS بدل خادم دائم، Sheets بدل قاعدة بيانات مُدارة، وملفات ساكنة بدل سيرفر SSR. وهذا يجعل المستودع كله قابلًا للتشغيل من أي شخص على حزمة GitHub المجانية.
