## قواعد هذا السجل

- قرار «مرفوض» يبقى مرفوضًا موثقًا — لا يُحذف لأنه «يحرج».
- أي قرار جديد يُضاف **قبل** الكود الذي ينفذه، أو في نفس الـPR — لا بعده.
- القرار الذي يُلغى يُصنَّف «مستبدَل بـADR-XXXX» ولا يُمحى.
- ما لا يهم هذا المستودع ولا يستطيع إثباته لا يُكتب هنا.
