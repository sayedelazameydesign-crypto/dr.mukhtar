# إعدادات العيادة من الواجهة (بدون برمجة)

هذا الدليل للطبيب/مالك العيادة. كل ما يظهر على الصفحة يُدار من **لوحة العيادة ← إعدادات العيادة**،
دون فتح الكود أو Script Properties، ودون إعادة نشر.

## حالة كل تعديل: هل ظهر للناس؟

| ما عدّلته | أين يظهر | هل يحتاج نشرًا؟ |
| --- | --- | --- |
| هوية العيادة والطبيب (اسم، هاتف، عنوان، ترخيص) | الصفحة العامة مباشرة | لا — فور الحفظ |
| ساعات الدوام وأيام الإغلاق | قائمة الأيام والأوقات | لا — فور الحفظ |
| أنواع الزيارات ومدتها | بطاقات نوع الزيارة ومدة الموعد | لا — فور الحفظ |
| رمز الدخول | شاشة دخول الفريق | لا — فور التغيير |
| نص جديد أو قسم جديد في الصفحة نفسها | تصميم الصفحة | **نعم** — هذا تغيير في الملفات لا في البيانات |
| مفتاح خدمة (مثل `GEMINI_API_KEY`) | لا يظهر في الواجهة إطلاقًا | يُدار في Script Properties فقط |

القاعدة: **الإعدادات تُنشر لحظة الحفظ، أمّا تغيير التصميم أو نص ثابت في الصفحة فيحتاج تحديث ملف ونشرًا.**

## الصفحة لا تكتب اسمًا ليس لك

حتى تُسجَّل بياناتك، الصفحة **لا تعرض** اسمًا أو تخصصًا أو رقم تواصل كأنه حقيقي:
الاسم يظهر «بيانات الطبيب لم تُسجَّل بعد»، والترخيص «غير منشور»، والهاتف «يُضاف من إعداد العيادة».
وفي لوحة العيادة يظهر **تنبيه أصفر** يقول «الصفحة لا تزال تعمل على بيانات افتراضية» ويسمّي الناقص،
وزرّه ينقلك إلى أول حقل ناقص.

لذلك عند أول دخول: البانر يخبرك بالضبط ما ينقص — عادةً خمسة حقول فقط.

ملاحظتان عمليتان:
- هذه الصفحة على GitHub Pages **نسخة عرض**: ما تحفظه هنا يبقى في متصفحك. النسخة التي تحفظ في
  سجل العيادة وتقويم الطبيب هي نسخة Google Apps Script (`docs/google-setup.md`).
- إن ظهرت الصفحة كأنها لم تتغيّر بعد تعديل ملفات، فهذا **كاش المتصفح**؛ أضف `?cb=` إلى الرابط.

## كيف أصل إلى الإعدادات؟

1. افتح الصفحة، ثم **«دخول العيادة»** (أعلى الصفحة أو في التذييل).
2. أدخل **رمز الدخول**.
3. اختر تبويب **«إعدادات العيادة»**.

!!! warning "رمز التهيئة"
    لا يوجد رمز مكتوب داخل المشروع. عند تشغيل `initializeCeliaKids()` **لأول مرة** يولّد النظام
    رمزًا عشوائيًا (٢٤ حرفًا) ويعرضه **مرة واحدة** في نتيجة التشغيل: احفظوه في مكان آمن.
    لا يُخزَّن الرمز كنص، بل بصمته (SHA-256) فقط — لا يمكن استرجاعه، وإن نسيتموه فالطريقة الوحيدة
    إعادة التهيئة أو تغييره من جلسة دخول قائمة.
    لوحة العيادة تعرض تنبيهًا أحمر حتى تغيّره من **«إعدادات العيادة ← رمز الدخول»**.

## ما الذي يمكن تعديله؟

| المجموعة | الحقول |
| --- | --- |
| **هوية العيادة** | اسم العيادة، الهاتف، العنوان، سطر تعريفي قصير |
| **هوية الطبيب** | الاسم واللقب العلمي، اللقب الوظيفي، التخصص الدقيق، **رقم ترخيص مزاولة المهنة** |
| **الدوام والمواعيد** | أيام العمل، أيام الإغلاق الأسبوعي، بداية ونهاية الدوام، الفاصل بين بدايات المواعيد |
| **أنواع الزيارات** | قائمة الخدمات ومدة كل نوع، سطر لكل نوع: `الاسم = المدة بالدقائق` |
| **رمز الدخول** | تغيير رمز الموظف (يتطلب الرمز الحالي) |

### أمثلة

- إضافة زيارة جديدة: في «أنواع الزيارات» أضف سطرًا `استشارة نمو = 20` ثم احفظ. يظهر نوع الزيارة
  على الصفحة فورًا، ويُحسب الوقت المتاح على أساس مدته.
- تقصير الدوام يومًا ما: «أيام العمل» و«نهاية الدوام»، ثم احفظ. الأوقات المعروضة تتغيّر مباشرة.
- إغلاق يوم محدد (إجازة): تبويب **«الطلبات والجدول» ← إغلاق يوم أو إجازة». لا تُعرض أوقات في ذلك
  اليوم، ويُرفض أي طلب جديد لذلك اليوم صراحةً.

## ما الذي لا يظهر في الشاشة؟

مفاتيح الخدمات ومعرّفات الأنظمة **لا تُعرض ولا تُحرَّر** من الواجهة؛ تبقى في إعدادات الخادم:

- `GEMINI_API_KEY` (المساعد الاختياري)
- `CALENDAR_ID` و`CELIA_SHEET_ID` (معرّفات داخلية)
- أي `GOOGLE_*` أو توكن وصول

هذا مقصود: الشاشة مخصّصة لما يحتاجه الطبيب يوميًا، وليس لأسرار التشغيل.

## GitHub Secrets and variables — هل أحتاجها؟

| نوع الإعداد | أين يُدار | هل تلمسه؟ |
| --- | --- | --- |
| **إعدادات العيادة** (الاسم، الهاتف، الدوام، الخدمات، الرمز) | لوحة العيادة ← إعدادات العيادة | **نعم، من الواجهة** |
| **إعدادات الخادم** (`ADMIN_PIN` سابقًا، `CALENDAR_ID`، `CELIA_SHEET_ID`، `GEMINI_API_KEY`) | Script Properties في Apps Script | نادرًا (مرة عند التجهيز) |
| **أسرار النشر** (`PAGES_TOKEN` لإنشاء موقع Pages تلقائيًا) | GitHub → Settings → Secrets and variables → Actions | اختياري تمامًا |
| **متغيرات النشر** (`PAGES_AUTO_ENABLE`, `NODE_VERSION`, …) | GitHub → Settings → Variables | اختياري تمامًا |

**الخلاصة:** صفحة GitHub التي رأيتها (`Repository secrets: هذا المستودع لا يحتوي أسرارًا`) **ليست
مكان إعدادات العيادة**، ولا حاجة لاستخدامها. الموقع منشور فعلًا بدون أي سر. أضف `PAGES_TOKEN`
فقط إن أردت أن ينشئ الـworkflow موقع Pages بنفسه في مستودع جديد.

## سجل التغييرات والاستعادة

- كل حفظ يُسجَّل في ورقة **Audit** ببيانات: مَن (موظف)، ماذا (أسماء الحقول)، قبل → بعد، وسبب
  التعديل إن كتبته. القيم الحسّاسة لا تُكتب أبدًا (الرمز يُسجَّل كـ`updated` فقط).
- زر **«استعادة الافتراضي لهذه المجموعة»** يعيد قيم المجموعة الحالية فقط، لا كل الإعدادات.
- عند رفض الحفظ تظهر رسالة عربية واضحة (مثال: «بداية الدوام يجب أن تسبق نهايته»)، ولا يُحفظ أي
  جزء من التغيير.

## التوسّع لاحقًا

إضافة إعداد جديد = **سطر واحد** في `CK_SETTINGS_CATALOG` داخل `Settings.gs`:

```js
{ key: 'CLINIC_LANDMARK', label: 'علامة مميزة قريبة', type: 'text', max: 80,
  help: 'تظهر أسفل العنوان في بطاقة العيادة' }
```

تظهر الحقول في الشاشة تلقائيًا، ويُتحقق منها على الخادم (الأنواع المدعومة: `text`, `phone`,
`time`, `int`, `weekdays`, `services`, `pin`). لعرض القيمة على الصفحة العامة أضف عنصرًا واحدًا
بـ`data-config="CLINIC_LANDMARK"` في `index.html` ومرّر المفتاح في `getClinicProfile`.
